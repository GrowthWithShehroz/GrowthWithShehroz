## 📋 Play Console form-fill checklist

Yeh fields kahaan ja kar bharne hain (in order):

### App content tab
| Field | Source |
|---|---|
| Privacy policy URL | `https://growthwithshehroz.github.io/GrowthWithShehroz/privacy.html` |
| Ads | **Yes** (banner + interstitial via AdMob) |
| App access | All functionality available without restrictions |
| Content rating | Run questionnaire — choose Reference/Books category |
| Target audience | **13+** (no children under 13) |

### Data safety form
Declare these collection categories:

| Category | Items | Required? | Shared? | Reason |
|---|---|---|---|---|
| Location | Approximate + Precise | **Optional** | No | Compute prayer times |
| App activity | App interactions | **Optional** | No | Analytics |
| App info & performance | Crash logs | **Optional** | No | Diagnose issues |
| Device or other identifiers | Device ID | **Optional** | Yes (with AdMob) | Ad personalization |

**Do NOT declare**: name, email, phone, address, SMS, photos, contacts.

### Store listing tab — Graphics required
| Asset | Spec | Status |
|---|---|---|
| App icon | 512×512 PNG, no transparency | ⏳ Currently placeholder; replace before public launch |
| Feature graphic | 1024×500 PNG | ⏳ Need to create |
| Phone screenshots | min 2, max 8, ≥1080×1920 | ⏳ Capture from installed AAB |
| Tablet screenshots | optional | Skip |

### Subscription product (one-time setup)
Path: Play Console → Monetize → Products → Subscriptions → **Create subscription**

| Field | Value |
|---|---|
| Product ID | `premium_monthly` |
| Name | Premium Monthly |
| Description | Removes ads, unlocks wisdom archive, custom Azan sounds |
| Base plan | Auto-renewing monthly |
| Price | $0.99 USD |
| Free trial | (optional) 7 days |

After creating: open RevenueCat → **Products** tab → ensure `premium_monthly`
is listed → **Offerings** → attach to entitlement `premium`.

## 🚀 Internal testing release flow

1. Play Console → **Testing → Internal testing → Create new release**
2. Upload your `.aab` file (from EAS build dashboard)
3. Paste the release notes above
4. Save → Review → **Start rollout to Internal testing**
5. Add your tester emails under **Testers** tab
6. Share the opt-in link with testers (link is in the Internal testing tab)
7. Wait ~1 hour for review
8. Install on tester devices via the Play Store opt-in flow
9. Verify on-device checklist from `README.md`
10. When confident → **Promote release → Production**

First production review: 1–7 days for new app.
